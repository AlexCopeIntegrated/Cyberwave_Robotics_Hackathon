# Frontend project

## Project info

This is the frontend application for your project.

## Running locally

The only requirement is having Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

Follow these steps:

```sh
npm install
npm run dev
```

## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Deployment

You can deploy this project to any static hosting provider that supports Vite/React apps (for example, Vercel, Netlify, or GitHub Pages).
